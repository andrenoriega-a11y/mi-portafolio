# Guía del Laboratorio anterior

## Introducción

Esta guía documenta los pasos necesarios para completar el proyecto anterior de forma exitosa. Puedes revisar la documentación oficial en [GitHub](https://github.com).

### Pasos de instalación y uso

- Clonar el repositorio en tu equipo local.
- Abrir la carpeta del proyecto en Visual Studio Code.
- Ejecutar la vista previa en tiempo real.

1. Instalar las dependencias o extensiones necesarias.
2. Verificar la correcta renderización del código Markdown.
3. Realizar las pruebas de sincronización con Git.
